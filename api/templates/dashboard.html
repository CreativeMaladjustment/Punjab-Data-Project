What these columns mean

Catalogue-entry extraction (partial/table data)

Attempted
Every page ever claimed for this model — the sum of every other column in this group.
Success
The model responded and its output parsed into a valid entry list. This includes pages the model correctly judged to have no catalogue entries (a cover, blank, or title page) — those succeed with zero entries, not a failure. The "(N entries)" figure is how many actual catalogue rows came out of the successful pages.
Content failed
The model did respond, but its response couldn't be parsed into the expected shape — malformed JSON, wrong structure, hallucinated fields. This is a model-output-quality problem, not a statement about the page itself (it does not mean "no text" or "don't look at this page again"). Each page gets up to 2 attempts total; once both fail this way, the page stops being reclaimed automatically and needs manual review or a different model.
Transient failed
Something failed before the model ever produced usable output, or after — a B2/network error fetching the image, a bad HTTP response from the model server, an unconfigured storage account, or a database error saving the result. Not the model's fault, and not capped: these keep getting retried on every future run indefinitely.
Claimed (active)
A worker currently has this page checked out and is presumably still working on it.
Claimed (stale)
A worker claimed this page but never recorded an outcome — most likely it crashed or the run was cancelled mid-page. Past the claim timeout, so it's eligible to be picked up again automatically; it isn't stuck.

Full-page OCR

Attempted / Success / Failed
A separate, independent pass that transcribes everything visible on the page — headers and other page furniture included, not just catalogue entries. Its outcome has no bearing on the extraction columns above, or vice versa: a page can succeed at one and fail the other.
