Content failed

The model responded, but its output couldn't be parsed into the expected shape — malformed JSON, wrong structure, invented fields. A quality problem with the model's output, not a statement about the page. Two attempts, then it stops being reclaimed.

Transient failed

Something broke around the model: a B2 fetch error, a bad HTTP response, a database write failure. Not capped — these keep retrying on every future run.

Claimed

A worker has the page checked out. Past the three-hour claim timeout it counts as stale and is fair game for another worker; it isn't stuck.

Full-page OCR

A separate pass that transcribes everything visible, page furniture included. Independent of extraction — a page can succeed at one and fail the other.
